# AI资本开支超级周期研究——资金闭环与偿付断点推演

一份基于公开数据的 AI 基础设施资本开支资金结构深度分析报告。

## 关于本项目

这份报告是我作为独立研究者完成的全栈战略分析项目，聚焦 2023 年以来 AI 基础设施资本开支的资金来源与循环结构，回答三个问题：这轮"万亿级"投入由谁买单、以何种方式买单、偿债链条可能在哪里断裂。

**我的角色**：独立完成从数据采集、框架搭建、结构推演到报告撰写的全流程。

**核心内容**：

- AI 资本开支资金闭环全景（"卖方融资"特征：投资方、供应商与客户高度重叠，投资回流为收入）
- 行业 AI 收入与资本开支比值测算（加权口径约 25-30%，缺口靠外部融资持续填补）
- 三类发行人偿付结构分类（母体现金流背书类 / 项目级无追索 SPV 类 / 纯玩家杠杆类）与各自的违约传播路径
- 执行日核验表（2026-09-06）与关键读数追踪
- 条件语句情景推演（"若 X 则 Y"）：不同利率、租金与需求路径下的偿付断点区间，不作方向性押注

**方法工具**：自研结构化推演框架（利益主体分析、结构性约束识别与趋势判断）+ 条件语句情景推演

**数据来源**：全部来自公开来源（截至 2026-09-06），关键数据均经执行日联网核验。
